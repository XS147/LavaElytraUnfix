# LavaElytraUnfix

> **Elytra are activated after only single tapping the "Jump" key when the player is in lava.**  
> **复原了 Mojang 在 26.3 修复的岩浆鞘翅 Bug：玩家在岩浆中单击跳跃键即可激活鞘翅，方便挖掘远古残骸。**

---

## 简介 / Introduction

**English:**  
LavaElytraUnfix is a lightweight mod that reverts Mojang's fix for MC-305535 in Minecraft 26.3. It lets you activate your Elytra with a single tap of the Jump key while in lava, making it easier to mine Ancient Debris and travel through lava lakes.

**中文：**  
LavaElytraUnfix 是一个轻量模组，用于取消 Mojang 在 Minecraft 26.3 中对 MC-305535 的修复。它允许你在岩浆中单击跳跃键激活鞘翅，方便挖掘远古残骸和在岩浆湖中移动。

---

## 背景 / Background

**English:**  
MC-305535 was a bug where players could activate Elytra with a single Jump press in lava. Mojang fixed it in 26.3. This mod restores the original single-tap behavior.

**中文：**  
MC-305535 是一个 Bug：玩家在岩浆中只需按一次跳跃键就能激活鞘翅。Mojang 在 26.3 中修复了它。本模组恢复了原来的单击激活行为。
